# Google Flow Video Prompts

Use these after generating the stills. In Google Flow, upload the matching still image as the first frame or scene reference, then paste the motion prompt.

Save every exported MP4 into:

```text
C:\Users\roopm\OneDrive\Documents\Claude_Celebratory_video\assets\video
```

After saving clips, run:

```powershell
npm run render
```

The render script will sync clips into Remotion automatically.
